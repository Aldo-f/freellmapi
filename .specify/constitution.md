# Project Principles

- **Feature-First Development**: Specs describe what and why, not how.
- **Backward Compatibility**: New features should not break existing functionality.
- **Testing First with Playwright E2E**: End-to-end tests are the primary method for validating features.
- **Agent-Executed QA**: All QA scenarios will be executed by agents, not humans.
- **Matching Codebase Conventions**: Adhere to existing patterns (shadcn/ui, Express patterns, etc.).
